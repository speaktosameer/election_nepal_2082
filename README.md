# Election Update 2082

This file documents the mobile-only UI improvements applied to the project. Desktop UI remains unchanged.

**Summary**

- Converted dense tables to card lists on small screens.
- Added touch-friendly spacing and larger menu buttons for mobile.
- Charts use horizontal scroll wrappers on mobile.
- Filters stack into a vertical column on small screens.
